# Security Advisories

This section contains security vulnerability disclosures and advisories for various systems and applications.

## Disclosure Policy

All vulnerabilities are disclosed following responsible disclosure practices:

1. **Initial Discovery**: Vulnerability identified during research
2. **Vendor Notification**: Security issue reported to affected vendor
3. **Coordination**: Working with vendor to develop fixes
4. **Public Disclosure**: Advisory published after patch availability or timeout
